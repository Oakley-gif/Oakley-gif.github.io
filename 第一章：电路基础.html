一、基本概念

1. 电流

  • 定义：单位时间内通过导体某横截面的电量

  • 公式：i = dq/dt

  • 单位：安培（A），1A = 1000mA

  • 方向：正电荷流动的方向

  • 直流电流：大小和方向都不随时间变化，用大写字母 I 表示

2. 电压

  • 定义：电场力把单位正电荷从A点移动到B点所做的功

  • 公式：u = dw/dq

  • 单位：伏特（V）

  • 电位：某点与参考点之间的电压

  • 方向：由高电位指向低电位

  • 恒定电压：大小和方向不随时间变化，用大写字母 U 表示

3. 参考方向

  • 关联参考方向：电流和电压的方向一致

  • 非关联参考方向：电流和电压的方向不一致

4. 电功率

  • 定义：单位时间内元件吸收或发出的电能

  • 公式：p = dw/dt = ui

  • 直流电路：P = UI = I²R = U²/R

二、电路元件

1. 电阻

  • 欧姆定律：i = u/R = Gu

  • 单位：欧姆（Ω）

  • 电导：G = 1/R，单位西门子（S）

2. 理想电压源

  • 输出电压恒定，与负载无关

  • Us = 0 时相当于短路

3. 理想电流源

  • 输出电流恒定，与负载无关

  • Is = 0 时相当于开路

4. 实际电压源

  • 理想电压源与电阻串联

  • U = Us - Rs·I

5. 实际电流源

  • 理想电流源与电阻并联

  • I = Is - U/Rs = Is - Gs·U

6. 电压源与电流源的等效变换

  • 电压源 → 电流源：电阻不变，I₁ = V₁/R₁

  • 电流源 → 电压源：电阻不变，V₁ = I₁·R₁

7. 电源的串并联

  • 电压源串联：V₃ = V₁ + V₂

  • 电流源并联：I₃ = I₁ + I₂

三、基尔霍夫定律

 

1. 基尔霍夫电流定律（KCL）

  • 内容：任一节点，流出（或流入）电流的代数和为零

  • 公式：ΣI = 0

  • 等价形式：流出电流之和 = 流入电流之和

2. 基尔霍夫电压定律（KVL）

  • 内容：沿任一闭合回路绕行一周，各支路电压代数和为零

  • 公式：ΣU = 0

 

 

四、简单电阻电路

1. 电阻串联

  • 等效电阻：R = R₁ + R₂ + ... + Rₙ

  • 分压公式：Uᵢ = [Rᵢ / (R₁+R₂+...+Rₙ)] · U

2. 电阻并联

  • 等效电阻：R = (R₁·R₂) / (R₁ + R₂)

  • 分流公式：I₁ = [R₂/(R₁+R₂)] · I，I₂ = [R₁/(R₁+R₂)] · I

五、支路电流法

解题步骤

  1. 确定支路数 m，选定支路电流参考方向

  2. 选定独立节点，应用KCL列出 n-1 个方程

  3. 选定独立回路，应用KVL列出 m-(n-1) 个方程

  4. 联立求解

  5. 用欧姆定律求支路电压

     

六、节点电位分析法

解题步骤

  1. 选定一个参考节点（电位为零）

  2. 用节点电位表示各支路电流

  3. 对独立节点应用KCL列方程

  4. 联立求解节点电位

  5. 求各支路电流和电压

 

七、叠加原理

要点

  • 只适用于线性电路

  • 某一电源单独作用时，其他电压源短路，电流源开路

  • 总响应 = 各电源单独作用的代数和

  • 功率不能用叠加原理计算（功率不是一次函数）

八、戴维南定理

内容

任一线性有源二端网络，可用一个电压源与电阻串联等效：

  • 电压源电压 = 开路电压 Uoc

  • 串联电阻 = 内部电源为零时的等效电阻 R₀

 

九、诺顿定理

内容

任一线性有源二端网络，可用一个电流源与电阻并联等效：

  • 电流源电流 = 短路电流 Isc

  • 并联电阻 = 内部电源为零时的等效电阻

十二、注意事项

  1. 参考方向：解题前必须明确标注各支路电流和电压的参考方向

  2. 独立方程数：

    • KCL独立方程 = 节点数 - 1

    • KVL独立方程 = 支路数 - 节点数 + 1

  3. 叠加原理：只能用于电压和电流，不能用于功率计算

  4. 受控源处理：受控源不能单独作用，需保留在所有分电路中

  5. 等效变换：电压源与电流源等效变换时，电阻大小不变，但要注意参考方向
